### (4)
次のア～オの全角記号を PC に入力したい。どのような語で漢字変換すればよいか答えよ。

- **解答**:
  - ア）≒：**いこーる**、**すうがく**（にあいこーる、きごう等も可）
  - イ）±：**ぷらまい**（ぷらすまいなす等も可）

  - オ）↓：**した**、**やじるし**
- **ポイント**: 講義ノート p.63 で紹介されている変換語（「から」「いこーる」「すうがく」「ぷらまい」「やじるし」）をそのまま覚えておくと確実です。
